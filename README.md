# Bureau PATH (Android)

Petite appli Android qui ouvre le bureau 3D de PATH (page Claude) en plein écran.
La progression, le directeur et les agents restent sur le compte Claude : l'appli affiche la vraie page.

- Construction automatique : GitHub Actions (outils Android officiels), à chaque envoi sur la branche `bureau-path-apk`.
- Téléchargement : onglet **Releases** → `Bureau-PATH.apk`
  (lien direct : `https://github.com/Vala973/automatique-game/releases/download/apk/Bureau-PATH.apk`).
- Première ouverture : se connecter à Claude avec « Continuer avec l'e-mail » (Google bloque sa connexion dans les applis intégrées).
